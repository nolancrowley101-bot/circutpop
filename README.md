# CircuitPop

CircuitPop is an educational circuit-building app for learning electronics by
building circuits on a visual grid canvas.

This repository contains the public CircuitPop website source. The site shows
the app, pricing, and purchase placeholders.

## Pricing

- Monthly: $10/month
- Yearly: $100/year

The purchase buttons are placeholders until payment links are connected.

## Download Access

Installer files are intentionally not committed to this public repository.
Downloads should only be provided through a payment-gated flow after purchase.

## Development

Requirements:

- Node.js `>=22.13.0`

Useful commands:

```bash
npm run install:ci
npm run dev
npm run build
```

The site is built with Next/Vinext for OpenAI Sites.
